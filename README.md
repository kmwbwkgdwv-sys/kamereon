# 🦎 ぬりかくれ！（ペイントかくれんぼ）

体をペイントして風景に溶け込む、ブラウザで遊べるオンラインかくれんぼゲームです。
Three.js（描画）＋ Firebase Realtime Database（通信）だけで動き、ビルド不要で GitHub Pages にそのまま公開できます。

## 遊び方

1. プレイヤー名を入力してスタート
2. ルームIDを入力して参加（同じIDの人と同じ部屋に。最大12人。無ければ新規作成）
3. まず全員「待合室」に入ります。歩き回ったりペイントの練習をしながら参加者を待てます
4. ホスト（👑）が「🏠 ルーム設定」でマップ・モード・笛の間隔などを決めて「ゲーム開始」

**マップ（5種類＋ランダム）** おうち / 公園 / 学校 / 倉庫 / 商店街

**見逃しランキング** 鬼の視界に入っているのに見つからなかった時間だけ、隠れている人にポイントが入ります（近いほど高得点、壁の陰は対象外）。隠れる側には常に最新、鬼側には30秒に1度だけ更新されます。

**笛** 設定した間隔（30〜120秒／オフ）で隠れている人から笛が鳴ります。聞こえるのは約24m以内だけ。音を消していても、鳴った方向の画面端が光ります（前＝上、後ろ＝下）。

**不正な隠れ場所の対策** マップ外には出られず、外壁は厚く、体のパーツが壁や家具にめり込むと外へ押し出されます。内壁は家具から登れない高さです。

| | |
|---|---|
| 🦎 カメレオン（隠れる側） | スポイトで壁や床の色を吸い取り、ブラシで体に直接ペイント。発光・メタリック・ツヤも調整可能。ポーズを変え、分身を最大2体置いて鬼を惑わす |
| 🔫 鬼（ハンター） | 隠れ時間が終わったらショットガンで探す。弾数に限りあり。分身を撃つと弾のムダ |
| 勝利条件 | 制限時間内に全員見つければ鬼の勝ち。1人でも生き残る／鬼が全員弾切れならカメレオンの勝ち |
| 増え鬼 | 見つかった人は鬼に寝返る。隠れる側は他の人の隠れ場所が見えない |
| ベーシック | 見つかった人は観戦に。鬼は増えない。隠れる側どうしは互いが見える |
| 答え合わせ | 終了後、全員の隠れ場所・見た目・分身を歩いて見て回れる |

**操作** PC: WASD 移動 / マウス 視点 / クリック 射撃 / Space ジャンプ / P ペイント / O ポーズ / F 分身 / ホイール カメラ距離
スマホ: 左スティック 移動 / 画面ドラッグ 視点 / ボタン

**設定** 軽量化モード・視点感度・BGM音量・効果音音量（端末に保存）

「ひとりで練習」は Firebase の設定なしで動きます（役割切替ボタンで鬼も試せます）。

## セットアップ

### 1. Firebase

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作成
2. **Authentication → Sign-in method → 匿名** を有効にする
3. **Realtime Database** を作成（ロックモードで OK）
4. **プロジェクトの設定 → マイアプリ → ウェブアプリを追加** し、表示された設定値を `firebase-config.js` に貼り付ける（`databaseURL` を忘れずに）
5. ルールを公開する（どちらか）
   - コンソール: Realtime Database → **ルール** タブに `database.rules.json` の中身を貼り付けて「公開」
   - CLI: `npm i -g firebase-tools && firebase login && firebase use --add && firebase deploy --only database`
6. GitHub Pages で公開する場合: Authentication → 設定 → **承認済みドメイン** に `ユーザー名.github.io` を追加

### 2. GitHub Pages

1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべてアップロード（push）
2. リポジトリの **Settings → Pages** → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存
3. 数分後 `https://ユーザー名.github.io/リポジトリ名/` で遊べます

```bash
git init && git add . && git commit -m "ぬりかくれ！" && git branch -M main
git remote add origin https://github.com/ユーザー名/リポジトリ名.git
git push -u origin main
```

## ルールで守っていること / 割り切り

- ログイン（匿名認証）した人だけが読み書きできる
- 1ルームの席は 0〜11 の12個だけ。席を取った人しかプレイヤー登録できない（13人目は入れない）
- 自分のプレイヤー情報・位置・スキン・分身は本人（とホスト）しか書けない
- 「見つけた」判定と分身の破壊だけは、同じルームの参加者なら書ける

サーバーを持たない構成のため、命中判定は撃った人の端末で行っています。また「増え鬼で他の隠れ場所が見えない」は画面に表示しないことで実現しており、通信内容を覗く改造までは防げません。友達同士で遊ぶ前提の作りです。
